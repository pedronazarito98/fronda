---
name: evidence-review
description: Revisar artefatos recebidos pelo Harness com proveniência e limites explícitos.
---

Carregue `harness_evidence_list` para localizar os artefatos desta tarefa.
Use `harness_evidence_read` nos artefatos compartilhados antes de descrever conteúdo visual.
Em vídeo, consulte instantes relevantes e cite os timestamps efetivamente fornecidos.
Compare o snapshot do artefato com o snapshot atual e identifique evidências obsoletas.
Relacione cada conclusão ao ID do artefato e ao critério correspondente.
Uma imagem recebida, um processo com exit 0 ou um frame isolado não comprovam sozinhos um fluxo inteiro.
Se faltar evidência, use `harness_capabilities` para procurar uma ferramenta apropriada; se não houver capacidade autorizada, explique o bloqueio.
Não repita chamadas com resultado incerto nem amplie permissões por conta própria.
