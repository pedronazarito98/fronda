# Fronda no Icon Composer

Abra `Fronda.icon` no Icon Composer. Há três camadas vetoriais: Haste orgânica, Copa de marfim e Ramo de argila. O fundo musgo é definido no documento; `background.svg` é a referência de cor para outros editores.

O documento foi criado, salvo e reaberto no Icon Composer instalado. As aparências Default e Dark foram inspecionadas. O sistema pode reinterpretar cor e reflexo conforme a aparência; isso é diferente do render estático texturizado.

As camadas usam um canvas de 1024×1024 sem máscara de canto embutida; o sistema fornece a forma externa e os efeitos. Não importar `app-icon-master.png` como um segundo fundo nesse arquivo.

Na integração, adicionar o .icon ao projeto e configurar o recurso de ícone. O pacote clássico em ../macos atende ao fluxo .icns/AppIcon.appiconset. Não há alteração do projeto nesta entrega.
